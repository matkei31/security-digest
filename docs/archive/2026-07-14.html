Today's Brief

本日の概況

本日は、Microsoft 365を標的とした高度なフィッシングサービス「Forg365」の出現が特に注目されます。これはデバイスコードフィッシングやAitM攻撃を組み合わせ、金融機関を含む多くの組織に認証情報窃取のリスクをもたらします。また、AIエージェントに偽の記憶を植え付ける「MemGhost」攻撃や、CISAのGitHub情報漏洩事例から学ぶべきクラウド認証情報管理の教訓も報告されており、新たな技術リスクと既存の運用課題の両面で警戒が必要です。全体として、攻撃手法の高度化とAI関連のリスクが顕著な一日でした。

本日の注目論点

  • Microsoft 365を標的とした高度なフィッシング攻撃が継続的に進化しており、多要素認証の強化だけでなく、デバイスコードフィッシングやAitM攻撃への具体的な対策、従業員への継続的な注意喚起と教育のあり方について議論が必要です。
  • AIエージェントの利用が拡大する中で、AIの記憶機能や学習プロセスに対する新たな攻撃手法が確認されており、AIシステムのセキュリティ対策、特に外部からの情報入力に対する検証メカニズムや、情報改ざん時の検知・復旧プロセスをどのように構築すべきか検討が必要です。
  • クラウド環境における認証情報の管理不備や委託先による情報漏洩事例が他業界で発生しており、自社のクラウド環境における認証情報管理の厳格化、公開リポジトリへの誤公開防止策、および委託先管理におけるセキュリティ要件と監査体制の強化について、改めて議論し見直す必要があります。

本日の確認事項

  • Microsoft 365の利用状況を確認し、デバイスコードフィッシングやAitM攻撃に対する防御策（条件付きアクセス、MFAの強化など）の適用状況を確認してください。
  • AIエージェントを利用している場合、MemGhost攻撃手法の原理と自社システムへの適用可能性について調査し、記憶機能や学習プロセスにおけるセキュリティ対策、特に外部からの情報入力に対する検証メカニズムを確認してください。
  • クラウド環境における認証情報の管理状況と、公開リポジトリへの誤公開防止策について、自社の運用状況を確認してください。
  • 自社および委託先が利用するルーターの設定状況を確認し、セキュリティベストプラクティスに沿っているか評価してください。

1.Forg365 PhaaS Targets Microsoft 365 with Device Code and AitM Session TheftForg365 PhaaS はデバイス コードと AitM セッション盗難で Microsoft 365 をターゲットにします

確認優先度 高確認目安 本日確認カテゴリ：攻撃・脅威動向
関連タグ：フィッシング認証クラウドインシデント情報漏えい

何が起きた

「Forg365」と呼ばれる新しいPhishing-as-a-Service (PhaaS)が、Microsoft 365アカウントを標的に、デバイスコードフィッシング、AitM戦術、アンチボット回避、AI支援のルアー作成、侵害後のメールボックス操作を組み合わせて攻撃しています。

なぜ金融機関に関係する

多くの金融機関でMicrosoft 365が利用されており、このPhaaSは高度なフィッシング手法を用いるため、認証情報の窃取やセッションハイジャックによる情報漏えい、不正アクセス、業務停止のリスクがあります。

確認すべきこと

  • Microsoft 365の利用状況を確認し、デバイスコードフィッシングやAitM攻撃に対する防御策（条件付きアクセス、MFAの強化など）の適用状況を確認してください。
  • 従業員に対し、デバイスコードフィッシングや不審な認証要求に対する注意喚起と教育を強化してください。
  • Microsoft 365のログ監視を強化し、不審な認証試行やセッションハイジャックの兆候がないか確認してください。

4.New MemGhost Attack Plants Persistent False Memories in AI Agents Through One Email新しい MemGhost 攻撃、1 通のメールで AI エージェントに永続的な偽の記憶を植え付ける

確認優先度 中確認目安 今週確認カテゴリ：AI・新技術リスク
関連タグ：AIAIエージェント

何が起きた

「MemGhost」と呼ばれる新たな攻撃手法が発見されました。これは、AIアシスタントに偽の記憶を植え付け、ユーザーに関する誤った情報を保存させ、その後の応答を密かに操作するものです。攻撃は1通のメールを通じて行われ、ユーザーはアシスタントが改ざんされたことに気づかない可能性があります。

なぜ金融機関に関係する

金融機関が顧客対応や業務効率化のためにAIエージェントを導入している場合、この攻撃手法によって顧客情報が誤って記憶されたり、誤った情報に基づいて応答が行われたりするリスクがあります。これにより、顧客との信頼関係の毀損や業務上の誤判断につながる可能性があります。

確認すべきこと

  • AIエージェントを利用している場合、本攻撃手法の原理と自社システムへの適用可能性について調査してください。
  • AIエージェントの記憶機能や学習プロセスにおけるセキュリティ対策、特に外部からの情報入力に対する検証メカニズムを確認してください。
  • AIエージェントが顧客情報を取り扱う場合、その情報が改ざんされないための対策や、改ざんされた場合の検知・復旧プロセスを検討してください。
