1.Compromised jscrambler 8.14.0 npm Release Drops Rust Infostealer During Install侵害された jscrambler 8.14.0 npm リリースにより、インストール中に Rust Infostealer がドロップされる

確認優先度 中確認目安 本日確認カテゴリ：攻撃・脅威動向
関連タグ：サプライチェーン情報漏えい悪用確認済み

何が起きた

jscrambler npmパッケージのバージョン8.14.0が侵害され、インストール時に情報窃取マルウェアが実行されるサプライチェーン攻撃が発生しました。この悪意あるバージョンは、Windows、macOS、Linux向けにビルドされたネイティブバイナリをドロップし実行します。

なぜ金融機関に関係する

金融機関が開発プロセスでjscrambler npmパッケージを利用している場合、開発環境やCI/CDパイプラインが侵害される可能性があります。これにより、機密情報や開発中のコードが窃取されるリスクがあります。

確認すべきこと

  • jscrambler npmパッケージのバージョン8.14.0が自社および委託先の開発環境やCI/CDパイプラインで利用されていないか確認してください。
  • 当該バージョンが利用されていた場合、影響を受けた環境の侵害有無を調査し、マルウェアの駆除と関連する認証情報の変更を検討してください。
  • 開発プロセスにおけるnpmパッケージの利用状況を棚卸し、サプライチェーンリスクに対するセキュリティ対策を見直してください。
