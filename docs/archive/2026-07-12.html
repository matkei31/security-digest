本日の概況

本日は、開発サプライチェーンにおける情報窃取マルウェアの拡散という緊急性の高いインシデントが報告されました。これは金融機関の開発環境やCI/CDパイプラインに直接的な影響を及ぼす可能性があります。また、Zimbraのメールクライアントに重大な脆弱性が発見されており、利用状況の確認と対応が求められます。さらに、AI技術の活用が進む中で、プロンプトインジェクション攻撃の新たな動向やAIガバナンスの重要性に関する情報が複数報告されており、中長期的なリスク管理の観点から注目されます。

本日の注目論点

  • 開発サプライチェーンにおけるソフトウェアコンポーネントのセキュリティリスクが顕在化しており、npmパッケージのような広く利用される開発ツールに対する継続的な監視と、サプライチェーン全体のセキュリティ対策の強化について議論が必要です。
  • AI技術の導入・活用が進む中で、プロンプトインジェクション攻撃など新たな脅威が具体化しています。金融機関におけるAI利用ガイドラインやセキュリティ対策において、これらのAI固有のリスクをどのように評価し、軽減していくべきか検討が求められます。
  • セッションハイジャック攻撃から認証情報を保護するための新しい技術（Device Bound Session Credentials: DBSC）の動向が報告されています。将来的な認証セキュリティの強化策として、このような先進技術の導入可能性や既存システムへの適用性について議論することが重要です。

本日の確認事項

  • jscrambler npmパッケージのバージョン8.14.0を利用している場合、直ちに利用を停止し、影響範囲を調査してください。
  • 開発環境やCI/CDパイプラインにおいて、npmパッケージのサプライチェーンセキュリティ対策が適切に講じられているか確認してください。
  • Zimbra Classic Web Clientを利用している場合、ベンダーの指示に従い、速やかにアップデートを適用し、社内システムおよび委託先を含めてZimbraの利用状況を確認してください。
  • AI技術を導入・活用している、または検討している場合、プロンプトインジェクション攻撃のリスクについて評価し、必要な対策を検討してください。

1.Compromised jscrambler 8.14.0 npm Release Drops Rust Infostealer During Install侵害された jscrambler 8.14.0 npm リリースにより、インストール中に Rust Infostealer がドロップされる

確認優先度 高確認目安 本日確認カテゴリ：インシデント
関連タグ：サプライチェーンインシデント情報漏えい

何が起きた

jscrambler npmパッケージのバージョン8.14.0が侵害され、インストール時に情報窃取マルウェアが実行される事態が発生しました。この悪意あるバージョンは2026年7月11日に公開され、Windows、macOS、Linux向けのネイティブバイナリをドロップ・実行するpreinstallフックを含んでいます。

なぜ金融機関に関係する

金融機関が開発プロセスでjscrambler npmパッケージを利用している場合、開発環境やCI/CDパイプラインが侵害され、機密情報が窃取されるリスクがあります。サプライチェーンリスクとして、委託先の開発環境への影響も考慮する必要があります。

確認すべきこと

  • jscrambler npmパッケージのバージョン8.14.0を利用している場合、直ちに利用を停止し、影響範囲を調査してください。
  • 開発環境やCI/CDパイプラインにおいて、npmパッケージのサプライチェーンセキュリティ対策が適切に講じられているか確認してください。
  • 開発環境やCI/CDパイプラインで情報窃取マルウェアの感染兆候がないか、ログやシステムアクティビティを調査してください。
