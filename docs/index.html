緊急 - セキュリティ上の脅威を理由に、ShareFile のお客様に Storage Zone Controller をシャットダウンするよう進捗状況が伝えられています

重要度 高本日確認カテゴリ：脆弱性・パッチ
悪用確認済みパッチインシデント

何が起きた

Progress Softwareは、ShareFileの顧客に対し、セキュリティ脅威に対応するため、Storage Zone Controllerを実行しているWindowsサーバーをシャットダウンするよう指示しました。同社は、影響を受けるアカウントへのアクセスを一時的に無効化しています。

なぜ金融機関に関係する

ShareFileのStorage Zone Controllerを利用している金融機関は、システム停止やデータ侵害のリスクに直面する可能性があります。業務継続性への影響や顧客データの保護に関する懸念が生じ得ます。

確認すべきこと

  • ShareFileのStorage Zone Controllerを利用している場合、Progress Softwareの指示に従い、直ちに該当サーバーをシャットダウンする。
  • Progress Softwareからの公式なセキュリティアドバイザリやパッチ情報を継続的に監視し、速やかに対応計画を策定・実行する。
  • 今回の事態が自社の事業継続計画やインシデント対応計画に与える影響を評価し、必要に応じて計画を更新する。

Injective Labs GitHub の侵害により、ウォレット キーを盗む npm パッケージがプッシュされる

重要度 中今週確認カテゴリ：インシデント
インシデントサプライチェーン情報漏えい

何が起きた

Injective LabsのGitHubリポジトリが侵害され、攻撃者は暗号通貨ウォレットの秘密鍵やニーモニックフレーズを盗む悪意のあるnpmパッケージを公開しました。この悪意のあるバージョンは、偽のテレメトリー機能を通じてデータを窃取しました。

なぜ金融機関に関係する

金融機関が直接Injective LabsのSDKを利用している場合、または関連する暗号通貨サービスを提供している場合、顧客のウォレット情報漏えいリスクに直結する可能性があります。サプライチェーン攻撃の一種として、開発環境や利用するオープンソースライブラリのセキュリティ管理の重要性を示唆します。

確認すべきこと

  • 自社または委託先でInjective LabsのSDKを利用している場合、影響を受けたnpmパッケージのバージョン（@injectivelabs/sdk-ts@1.20.21）が使用されていないか確認する。
  • 開発環境におけるオープンソースライブラリの利用状況を棚卸し、サプライチェーンリスク管理のプロセスを見直す。
  • 開発者が利用するGitHubリポジトリやnpmレジストリからのパッケージ導入におけるセキュリティチェック体制を強化する。

U-Boot の 6 つの新たな欠陥により、悪意のあるイメージがデバイスをクラッシュさせたり、起動時にコードを実行したりする可能性があります

重要度 中今週確認カテゴリ：脆弱性・パッチ
パッチサプライチェーン

何が起きた

ファームウェアセキュリティ企業Binarlyの研究者が、U-Bootに6つの新たな脆弱性を発見しました。これらの脆弱性は、ホームルーター、スマートカメラ、データセンターサーバーの管理チップなど、様々なハードウェアの起動時に悪意のあるイメージを介してデバイスをクラッシュさせたり、コードを実行させたりする可能性があります。

なぜ金融機関に関係する

U-Bootは幅広い組み込みシステムで利用されており、金融機関が利用するネットワーク機器、IoTデバイス、データセンターのサーバー管理チップなどに影響を与える可能性があります。これらの脆弱性が悪用された場合、システムの可用性低下や不正なコード実行による情報漏えい、業務停止につながるリスクがあります。

確認すべきこと

  • 自組織で利用している機器やシステムにU-Bootが組み込まれているかを確認する。
  • U-Bootの脆弱性に関するベンダーからの情報提供を監視し、該当する場合はパッチ適用計画を策定する。
  • サプライチェーンを通じて導入される機器のファームウェアセキュリティについて、調達基準や委託先管理の観点から確認する。

CrowdStrike

ガードレールのない AI ガバナンスが劇場である理由

重要度 中今週確認カテゴリ：AI・新技術リスク
AIガイドライン

何が起きた

CrowdStrikeは、AIガバナンスが実効性を持つためには、具体的なガードレール（安全策）が不可欠であると指摘しています。ガードレールがなければ、AIガバナンスは形だけのものになりかねません。

なぜ金融機関に関係する

金融機関がAI技術を導入・活用する際、単にAIガバナンス体制を構築するだけでなく、具体的なリスク軽減策としてのガードレールを実装しなければ、AI利用に伴う潜在的なリスク（誤情報、倫理問題、セキュリティ脆弱性など）を適切に管理できない可能性があります。

確認すべきこと

  • AI導入・活用における既存のガバナンスフレームワークに、具体的なガードレール（例: データ入力検証、出力フィルタリング、利用ポリシー）が組み込まれているかを確認する。
  • AI利用に伴うリスク評価プロセスにおいて、ガードレールの有効性評価を組み込み、継続的に監視・改善する計画を策定する。
  • AI利用に関する従業員への教育・トレーニングに、ガードレールの重要性と具体的な運用方法を含めることを検討する。

デバイスにバインドされたセッション認証情報による Cookie の保護

重要度 中今週確認カテゴリ：攻撃・脅威動向
認証

何が起きた

Google TAGは、セッションハイジャック攻撃からクッキーを保護するための新しい技術「Device Bound Session Credentials (DBSC)」について解説しています。DBSCは、セッションクッキーをデバイスにバインドすることで、攻撃者が盗んだクッキーを使用できないようにします。

なぜ金融機関に関係する

確認すべきこと

  • セッションハイジャック攻撃の手法と、それに対する現在の自組織の防御策を確認する。
  • DBSCのような新しい認証技術の動向を継続的に調査し、将来的な導入可能性について検討する。
  • 既存の認証システムにおけるセッキー保護の強化策について、ベンダーや専門家と情報交換を行う。
