「金融庁における政策評価に関する基本計画」について公表しました。

重要度 低

要約

金融庁が「金融庁における政策評価に関する基本計画」を公表しました。これは政策の有効性や効率性を評価するための基本方針です。

金融機関への影響

金融機関のシステムや業務に直接的な影響はありません。金融庁の内部的な政策評価に関する情報であり、委託先への影響もありません。

推奨アクション

  • 金融機関の業務やシステムへの直接的な影響はないため、特段の対応は不要です。
  • 金融庁の政策評価の動向として、必要に応じて情報収集の対象とすることができます。

「金融商品取引法の審判手続等における参考人及び鑑定人の旅費及び手当に関する政令の一部を改正する政令」及び「公認会計士法の審判手続における参考人及び鑑定人の旅費及び手当に関する政令の一部を改正する政令」の公布及びパブリックコメントの結果について公表しました。

重要度 低

要約

金融庁は、金融商品取引法および公認会計士法の審判手続における参考人・鑑定人の旅費・手当に関する政令改正を公布し、パブリックコメントの結果を公表しました。

金融機関への影響

本件は、金融機関のシステム、業務、委託先への直接的な影響は限定的です。審判手続に関与する可能性のある法務部門やコンプライアンス部門は、関連規定の変更を確認する必要があります。

推奨アクション

  • 法務・コンプライアンス部門は、改正政令の内容を確認し、審判手続における旅費・手当の変更点を把握する。
  • 関連する内部規程やマニュアルがある場合、必要に応じて改正内容を反映させるか、周知を検討する。

推奨アクション

  • 公表された議事次第を確認し、自社の業務に関連する議題や論点がないか確認する。
  • 特段の緊急対応は不要だが、今後の金融トラブルに関する動向として情報収集を継続する。
