ウクライナ、ロシア諜報機関が偽のサポートテキストを使用してメッセージング資格情報を盗んだと発表

重要度 中

要約

ウクライナ保安庁（SSU）とFBIは、ロシア情報機関がウクライナ、欧州、米国の政府関係者などを標的に、偽の支援テキストでメッセージングアカウントの認証情報を窃取するサイバー攻撃を継続的に行っていたことを公表しました。

金融機関への影響

金融機関の従業員が標的となる可能性があり、個人利用のメッセージングアプリの認証情報が窃取されると、業務端末への不正アクセスや情報漏えいのリスクがあります。特に、公務を兼ねる役職員は注意が必要です。

推奨アクション

  • 従業員に対し、不審なメッセージやリンクを開かないよう注意喚起し、多要素認証の利用を徹底するよう指示する。
  • 個人利用のメッセージングアプリが業務に利用されていないか確認し、利用されている場合は情報セキュリティポリシーを再周知する。
  • 標的型攻撃メール訓練やフィッシング詐欺対策訓練に、SMSやメッセージングアプリを介した攻撃シナリオを追加することを検討する。

OpenAI、アクセス制限とより強力なサイバー安全対策を備えた GPT-5.6 Sol をプレビュー

重要度 低

要約

OpenAIが米国政府との連携の一環として、最新のGPT-5.6（Sol、Terra、Luna）を一部企業に限定プレビュー公開しました。

金融機関への影響

現時点では限定的なプレビューであり、金融機関のシステムや業務への直接的な影響は低いと考えられます。将来的にOpenAI製品を導入する際の性能やセキュリティの評価に影響する可能性があります。

推奨アクション

  • OpenAI製品の利用状況を確認し、将来的な導入計画がある場合は本モデルの動向を継続的に情報収集する。
  • AIモデルの利用に関する社内ガイドラインやセキュリティ要件が最新であることを確認する。

FBI、ロシアの諜報ハッカーが信号バックアップ回復キーをターゲットに警告

重要度 高

要約

FBIとCISAは、ロシアの情報機関がSignalアカウントへのフィッシング攻撃を更新し、Signalバックアップリカバリーキーの詐取を試みていると警告しました。

金融機関への影響

役職員が業務連絡にSignalを利用している場合、メッセージ履歴の閲覧やアカウント乗っ取りにより、機密情報漏えいや不正取引のリスクがあります。委託先との連絡にも注意が必要です。

推奨アクション

  • 役職員に対し、Signalバックアップリカバリーキーの重要性と、いかなる場合も他者に開示しないよう緊急で注意喚起する。
  • Signalの利用状況（業務利用の有無、利用部署、利用目的）を調査し、リスクアセスメントを実施する。
  • Signalの利用が確認された場合、代替のセキュアなコミュニケーションツールの導入を検討し、移行計画を策定する。
