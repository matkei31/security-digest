ShapedPlugin WordPress Pro プラグインがサプライチェーン攻撃でバックドア化

重要度 中

要約

ShapedPluginが提供する複数のWordPress Proプラグインがサプライチェーン攻撃を受け、公式リリースチャネルを通じてバックドアが仕込まれたバージョンが配布されました。

金融機関への影響

WordPressを利用しているウェブサイトを持つ金融機関は、ShapedPluginのProプラグインを導入している場合、システムへの不正アクセスや情報漏えいのリスクがあります。特に顧客向けサービスや情報公開サイトで利用している場合は影響が大きいです。委託先がWordPressサイトを運用している場合も確認が必要です。

推奨アクション

  • 自社および委託先がShapedPluginのWordPress Proプラグインを利用しているか、全サイトを棚卸しして確認する。
  • 対象プラグインが導入されている場合、速やかに公式情報を確認し、安全なバージョンへのアップデートまたは利用停止を検討する。
  • ウェブサイトのアクセスログやセキュリティログを監視し、不審な活動がないか確認を強化する。

研究者は、テナント間で AI チャットを公開する可能性がある Dify の DifyTap の欠陥を詳しく説明しています

重要度 中

要約

サイバーセキュリティ研究者が、オープンソースのAIプラットフォームDifyにDifyTapと総称される4つの脆弱性を公表しました。これにより、認証なしで他テナントのAIチャット内容が閲覧される可能性があります。

金融機関への影響

Difyを直接利用している場合、AIチャットの機密情報漏えいのリスクがあります。また、AI関連サービスを提供する委託先がDifyを利用している場合、間接的な情報漏えいリスクや業務影響が生じる可能性があります。

推奨アクション

  • Difyの利用状況（直接利用、委託先の利用）を確認し、利用している場合は速やかに脆弱性対応状況をベンダーに確認してください。
  • Difyを利用している場合、または委託先が利用している場合は、機密情報を取り扱うAIチャットの利用を一時的に制限することを検討してください。
  • Difyの脆弱性に関する追加情報を継続的に収集し、必要な対策を講じるための計画を策定してください。

29 年前から存在する Squid プロキシのバグ「Squidbleed」により平文の HTTP リクエストが漏洩する可能性がある

重要度 中

要約

Calif.ioの研究者が、Squid Webプロキシに29年前から存在する脆弱性「Squidbleed」を公表しました。これにより、HTTPリクエストの平文情報が漏洩する可能性があります。

金融機関への影響

Squidプロキシを利用している場合、認証情報やセッショントークンを含むHTTPリクエストが他のプロキシ利用者へ漏洩するリスクがあります。特に、インターネット接続や内部システム連携に利用している場合は、情報漏洩や不正アクセスの懸念が生じます。

推奨アクション

  • 自組織および委託先でSquidプロキシの利用状況を確認し、バージョン情報を特定する。
  • Squidプロキシを利用している場合、速やかにベンダーからのパッチ適用または設定変更による緩和策を検討・実施する。
  • プロキシ経由の通信における機密情報の取り扱いについて、改めてセキュリティポリシーを再確認し、必要に応じて強化する。
