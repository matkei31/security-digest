BeyondTrust、リモート サポートと PRA の重大な認証バイパスの欠陥にパッチを適用

重要度 高

要約

BeyondTrustがRemote Support (RS) およびPrivileged Remote Access (PRA) 製品の認証バイパスの脆弱性(CVE-2026-40138)を修正するアップデートを公開しました。認証されていない攻撃者が影響を受けるデバイスを制御する可能性があります。

金融機関への影響

BeyondTrust RS/PRAを利用している場合、システムへの不正アクセス、機密情報漏えい、業務停止のリスクがあります。特に特権アクセス管理に関わるシステムは影響が大きいです。委託先での利用状況も確認が必要です。

推奨アクション

  • BeyondTrust RS/PRA製品の利用有無を確認し、利用している場合は速やかにベンダーの指示に従いアップデートを適用してください。
  • BeyondTrust製品を利用している委託先に対し、本脆弱性への対応状況を確認し、必要に応じて改善を求めてください。
  • アップデート適用が困難な場合は、一時的な緩和策の有無を確認し、アクセス制御の強化や監視体制の強化を検討してください。

イラン関連のハッカーが新しいCavern C2フレームワークを使用してイスラエルの組織を標的に

重要度 中

要約

イラン政府系ハッカー集団が、イスラエル組織を標的に、未確認のC2フレームワーク「Cavern」を使用していることをCheck Point Researchが公表しました。

金融機関への影響

直接的な金融機関への影響は低いですが、ITプロバイダーが標的とされているため、委託先のセキュリティ状況を確認する必要があります。サプライチェーンリスクとして、間接的な影響が生じる可能性があります。

推奨アクション

  • 委託先のITプロバイダーに対し、本攻撃に関する情報収集と対策状況を確認する。
  • 自組織のシステムログを監視し、Cavern C2フレームワークに関連する不審な通信がないか確認する。
  • 脅威インテリジェンス情報を継続的に収集し、新たな攻撃手法やC2フレームワークへの対応を検討する。

「BusySnake」情報窃盗犯が重要インフラネットワークに侵入

重要度 中

要約

Armored Likhoが「BusySnake」情報窃取マルウェアを使用し、ロシア、ブラジル、カザフスタンの政府機関や電力会社に侵入したとDark Readingが報じました。

金融機関への影響

直接的な金融機関への影響は不明ですが、サプライチェーンや決済インフラを介した間接的な影響の可能性があります。委託先のセキュリティ状況を確認し、関連リスクを評価する必要があります。

推奨アクション

  • 委託先や取引先が攻撃対象となったインフラ事業者と関連がないか、情報収集と確認を行う。
  • 自組織のシステムでBusySnakeのIoC（存在する場合）に合致する活動がないか、ログを監視・分析する。
  • インフラ事業者への攻撃が金融サービスに波及する可能性を評価し、事業継続計画への影響を検討する。

Citrix が再び出血? NetScaler の脆弱性が攻撃を受ける

重要度 高

要約

Dark Readingが、Citrix NetScaler製品の新たなメモリ情報漏えい脆弱性(CitrixBleed)について、PoC公開後すぐに攻撃者が悪用を開始したと報じました。

金融機関への影響

Citrix NetScaler製品を利用している金融機関は、システムからの機密情報漏えいや不正アクセスにつながる可能性があります。特に外部公開システムは緊急の対応が必要です。

推奨アクション

  • 自組織および委託先におけるCitrix NetScaler製品の利用状況を確認し、脆弱性の有無を特定する。
  • Citrixが提供するセキュリティパッチや緩和策を速やかに適用し、システムを保護する。
  • 不審な通信やアクセスがないか、ログ監視を強化し、異常を検知した場合は即座に対応する。
