Splunk Enterprise の重大な欠陥により、攻撃者は認証なしでコードを実行できる

重要度 高

要約

Splunk社がSplunk Enterpriseの深刻な脆弱性CVE-2026-20253を公表し、認証なしでファイル操作やリモートコード実行が可能となるため、セキュリティアップデートをリリースしました。

金融機関への影響

Splunk Enterpriseを利用しているシステムは、認証なしで攻撃者にシステムを操作されるリスクがあります。ログ管理、セキュリティ監視、IT運用業務に影響し、情報漏えいやシステム停止につながる可能性があります。

推奨アクション

  • 自組織および委託先におけるSplunk Enterpriseの利用状況とバージョンを緊急で確認する。
  • 脆弱性の影響を受けるバージョンを使用している場合、速やかにSplunk社が提供するセキュリティアップデートを適用する。
  • アップデート適用が困難な場合は、Splunk社の公開情報を確認し、緩和策の有無と適用を検討する。

米国、Anthropicに外国人のFable 5とMythos 5へのアクセスを一時停止するよう命令

重要度 高

要約

米国政府は国家安全保障上の懸念から、Anthropic社に対し、AIモデル「Claude Fable 5」と「Mythos 5」への外国籍利用者のアクセスを停止するよう命令しました。これを受け、Anthropic社は全ユーザーのアクセスを突如無効化すると発表しました。

金融機関への影響

Anthropic社のAIモデルを業務利用している場合、システム連携や業務プロセスが停止する可能性があります。特に外国籍の従業員が利用している場合、業務継続に直接的な影響が生じ、代替手段の検討が急務となります。

推奨アクション

  • Anthropic社のAIモデル（Claude Fable 5, Mythos 5）の利用有無と利用状況を緊急で確認する。
  • 利用している場合、当該モデルに依存する業務プロセスやシステムへの影響範囲を特定し、代替策を検討・準備する。
  • 外国籍の従業員によるAIモデル利用状況を確認し、業務への影響と情報管理の適切性を評価する。
The Hacker News 06/13 01:03

Infostealer と eBPF ルートキットを展開するために 400 以上の Arch Linux AUR パッケージがハイジャックされる

重要度 中

要約

The Hacker Newsが、Arch LinuxのコミュニティパッケージリポジトリAURで400以上のパッケージが乗っ取られ、認証情報窃取マルウェアとeBPFルートキットをインストールするよう改ざんされたと報じました。

金融機関への影響

Arch Linuxを開発環境や一部システムで利用している場合、開発者の認証情報漏洩やシステムへの不正アクセスリスクがあります。直接的な金融サービスへの影響は低いですが、サプライチェーンリスクとして委託先での利用状況確認が必要です。

推奨アクション

  • Arch Linuxの利用状況（特にAURパッケージ）をシステム部門と開発部門で確認し、影響範囲を特定する。
  • AURパッケージを利用している場合、改ざんされたパッケージの有無と、認証情報窃取マルウェア感染の有無を調査する。
  • 開発環境や本番環境でArch Linuxを利用している委託先に対し、本件に関する注意喚起と対応状況の確認を行う。
