ハッカーが Gravity SMTP WordPress プラグインのバグを悪用して API キーを公開

重要度 中

要約

The Hacker Newsが、WordPressプラグイン「Gravity SMTP」の脆弱性(CVE-2026-4020)が悪用され、APIキーなどの機密情報が漏えいしていると報じました。

金融機関への影響

金融機関がWordPressをウェブサイトやマーケティング目的で利用し、Gravity SMTPプラグインを使用している場合、設定情報やAPIキーが漏えいし、関連システムや委託先への不正アクセス、情報漏えいリスクがあります。

推奨アクション

  • 自組織および委託先でGravity SMTPプラグインの利用状況を確認し、利用している場合は速やかに最新バージョンへアップデートする。
  • Gravity SMTPプラグインを使用している場合、設定情報やAPIキーの漏えいの有無をログ等で確認し、必要に応じてAPIキーを再発行する。
  • WordPressサイトのセキュリティ設定全般を見直し、不要なプラグインの削除やアクセス制御の強化を検討する。
The Hacker News 06/20 00:07

パッチ不可能な「usbliter8」エクスプロイトにより Apple A12 および A13 SecureROM ブート チェーンが破壊される

重要度 中

要約

セキュリティ研究者がApple A12/A13チップのSecureROMに任意のコード実行を可能にする「usbliter8」エクスプロイトを公表しました。この脆弱性はハードウェアに起因するため、ソフトウェアアップデートでは修正できません。

金融機関への影響

金融機関が従業員に貸与しているiPhoneやiPad（A12/A13チップ搭載モデル）が物理的に不正アクセスされた場合、情報漏えいや不正利用のリスクがあります。顧客向けアプリやシステムへの直接的な影響は低いですが、端末管理ポリシーの見直しが必要です。

推奨アクション

  • A12/A13チップ搭載のAppleデバイス（iPhone XS/XR/11/SE2など）の利用状況と配布状況を確認する。
  • 該当デバイスの物理的なセキュリティ対策（紛失・盗難対策、MDMによる管理強化）を再評価し、必要に応じて強化する。
  • 機密情報を取り扱う業務での該当デバイスの利用について、代替手段の検討や利用制限を検討する。
The Hacker News 06/20 00:03

The Gentlemen RaaS は 400 のセキュリティ プロセスを対象とした GentleKiller EDR フレームワークを使用

重要度 高

要約

The Hacker Newsが、Gentlemen RaaSがGentleKiller EDRフレームワークを開発し、400のセキュリティプロセスを標的にしてEDRを無効化していると報じました。

金融機関への影響

金融機関のシステム、特にエンドポイントセキュリティ製品（EDR）が標的となるリスクがあります。これにより、ランサムウェア攻撃に対する防御が低下し、情報漏えいや業務停止に繋がる可能性があります。委託先のセキュリティ対策も確認が必要です。

推奨アクション

  • 導入しているEDR製品がGentleKillerの標的となるプロセスに含まれていないか、ベンダー情報を確認する。
  • EDR製品の検知・防御ログを定期的に確認し、不審なプロセス終了やEDR機能停止の兆候がないか監視を強化する。
  • 委託先に対し、GentleKillerによるEDR無効化攻撃への対策状況と、導入EDR製品の対応状況を確認する。
