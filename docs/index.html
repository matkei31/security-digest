ShinyHunters が Oracle PeopleSoft Zero-Day (CVE-2026-35273) を悪用して大学に侵入

重要度 中

要約

ShinyHuntersがOracle PeopleSoftの未修正の脆弱性(CVE-2026-35273)を悪用し、大学のシステムに侵入してデータを窃取し、身代金を要求しました。活動期間は5月27日から6月9日です。

金融機関への影響

Oracle PeopleSoftを利用している場合、システムへの不正アクセス、機密情報漏えい、業務停止のリスクがあります。特に人事・財務関連システムへの影響が懸念されます。委託先での利用状況も確認が必要です。

推奨アクション

  • 自組織および委託先におけるOracle PeopleSoftの利用有無とバージョンを確認する。
  • Oracle PeopleSoftを利用している場合、Oracleからの公式パッチ適用状況を確認し、速やかに適用を検討する。
  • PeopleSoft関連システムへの不審なアクセスやデータ流出の痕跡がないか、ログを調査する。

重要度 中

要約

Dark Readingが、フィッシング攻撃の総量は20%減少したが、AI活用により攻撃の質が向上し、リスクは上昇していると報じました。

金融機関への影響

金融機関の顧客や従業員を狙ったフィッシング詐欺の巧妙化により、不正送金や情報漏えいのリスクが高まります。特にAIによる偽装は、既存の検知システムをすり抜ける可能性があります。

推奨アクション

  • 従業員向けにAIを活用した最新のフィッシング手口に関する注意喚起と教育を強化する。
  • メールセキュリティシステムの設定を見直し、AI生成コンテンツの検知機能の有無を確認・強化する。
  • 顧客に対し、フィッシング詐欺の手口が巧妙化している旨を注意喚起し、不審な連絡への警戒を促す。
