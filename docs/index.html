Linux カーネルの新たな「Bad Epoll」欠陥により、特権のないユーザーが root 権限を取得し、Android に被害を与える

重要度 高

要約

Linuxカーネルの新たな脆弱性「Bad Epoll」（CVE-2026-46242）が公開され、一般ユーザーがroot権限を取得できることが判明しました。Linuxデスクトップ、サーバー、Androidに影響し、修正パッチがリリースされています。

金融機関への影響

LinuxサーバーやAndroidデバイスを利用するシステム、特に顧客情報や取引データを扱う基幹システム、情報系システム、開発環境、VDI環境、ATM、POSシステム、モバイルバンキングアプリ等に影響し、情報漏えいやシステム停止、不正取引のリスクがあります。委託先のシステムも確認が必要です。

推奨アクション

  • Linuxカーネルのバージョンを確認し、影響を受けるシステムを特定する。
  • 速やかに修正パッチを適用し、システムをアップデートする。
  • パッチ適用が困難な場合は、緩和策の検討と監視強化を行う。

新しい Avalon マルウェア フレームワーク パック CrownX ランサムウェア機能

重要度 中

要約

サイバーセキュリティ研究者が、従来のセキュリティ対策を回避する多段階のフィッシング攻撃で拡散される、新たなモジュール型マルウェアフレームワーク「Avalon」を発見しました。

金融機関への影響

Avalonは認証情報窃取、ラテラルムーブメント、ランサムウェア実行などの機能を持ち、金融機関のシステムへの不正アクセス、情報漏えい、業務停止のリスクを高めます。特に、委託先経由での感染経路にも注意が必要です。

推奨アクション

  • 従業員に対し、多段階フィッシング攻撃の手口とAvalonマルウェアに関する注意喚起と教育を実施する。
  • メールセキュリティシステムの設定を見直し、フィッシングメールの検知・ブロック能力を強化する。
  • システムログを監視し、Avalアンマルウェア感染の兆候（不審な認証情報アクセス、横展開の試みなど）がないか確認する。
