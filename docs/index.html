悪意のある Perplexity Chrome 拡張機能により検索とアドレス バー入力が傍受される

重要度 中

要約

Microsoftが、AI検索エンジンPerplexityを装った悪意のあるChrome拡張機能を発見しました。この拡張機能は、検索クエリとアドレスバーへの入力を攻撃者サーバー経由でログに記録していました。

金融機関への影響

従業員が業務利用するPCのChromeブラウザに当該拡張機能がインストールされていた場合、機密情報を含む検索履歴やURL入力が漏洩した可能性があります。特に、クラウドサービスへのログイン情報や社内システムへのアクセス情報が入力された場合、不正アクセスや情報漏洩のリスクが高まります。

推奨アクション

  • 全従業員のPCでChromeブラウザの拡張機能リストを確認し、「Perplexity AI」という名称の拡張機能がインストールされていないか確認してください。
  • もし該当の拡張機能が発見された場合、直ちにアンインストールし、システム管理部門へ報告してください。
  • 従業員に対し、公式ストア以外からの拡張機能のインストールを禁止し、不審な拡張機能について注意喚起を行ってください。

WhatsApp、ついに電話番号を非公開にするためにユーザー名を取得

重要度 低

要約

WhatsAppがユーザーのプライバシー保護のため、電話番号の代わりに利用できるユーザー名の提供を公式に発表しました。

金融機関への影響

WhatsAppのユーザー名機能は、金融機関の顧客や従業員がプライベートなコミュニケーションで電話番号を共有せずに済むため、個人情報保護の観点からプラスの影響があります。ただし、金融機関のシステムや業務への直接的な影響は限定的です。

推奨アクション

  • 従業員に対し、WhatsApp利用時の個人情報保護意識向上と、新機能の適切な利用を周知する。
  • 顧客サポートチャネルにおけるWhatsApp利用ガイドラインを見直し、ユーザー名機能の導入を検討する。

「Djinn」スティーラーはクラウド、AI認証情報を狙う

重要度 中

要約

Dark Readingが、情報窃取マルウェア「Djinn Stealer」がSimpleHelpの認証バイパス脆弱性CVE-2026-48558を悪用し、クラウドやAI関連の認証情報を標的にしていると公表しました。

金融機関への影響

SimpleHelpをリモートサポートやシステム管理に利用している場合、開発・管理環境から企業システムへの認証情報が窃取されるリスクがあります。クラウドやAIサービスの利用状況によっては、不正アクセスや情報漏えいにつながる可能性があります。

推奨アクション

  • SimpleHelpの利用有無を確認し、利用している場合はCVE-2026-48558のパッチ適用状況を至急確認する。
  • クラウドサービスやAI関連システムの認証情報管理状況を再点検し、多要素認証の徹底やアクセス権限の最小化を検討する。
  • 委託先がSimpleHelpを利用しているか確認し、脆弱性対応状況と認証情報管理について情報提供を求める。
