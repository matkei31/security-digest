Crypto Clipper キャンペーンが偽レビュー、AI ナレーター、VirusTotal Comments を悪用

重要度 中

要約

Check Point Researchが、未知の攻撃者が正規ニュースサイトの有料記事、偽レビュー、AIナレーター、VirusTotalコメントを悪用し、不正なクリプトクリッパーキャンペーンを展開していることを公表しました。

金融機関への影響

金融機関の顧客が、偽のソフトウェアダウンロードを通じてクリプトクリッパーに感染する可能性があります。これにより、仮想通貨取引時のアドレスが窃取され、不正送金や資産損失のリスクが高まります。金融機関のシステムへの直接的な影響は低いですが、顧客資産保護の観点から注意が必要です。

推奨アクション

  • 顧客に対し、信頼できないソースからのソフトウェアダウンロードや仮想通貨関連ツールの利用を避けるよう注意喚起を実施する。
  • 仮想通貨関連サービスを提供する部門は、顧客の不審な取引や資産移動に関する問い合わせ増加に備え、監視体制を強化する。
  • 従業員向けに、フィッシングサイトや不正なソフトウェアの識別に関するセキュリティ教育を再徹底し、情報資産の保護を促す。

Microsoft、RoguePlanet Defenderのゼロデイを確認、パッチは開発中と発表

重要度 高

要約

Microsoftは、Defenderのゼロデイ脆弱性「RoguePlanet」（CVE-2026-50656、CVSS:7.8）を正式に公表し、現在パッチを開発中であることを明らかにしました。

金融機関への影響

Microsoft Defenderを利用している金融機関のシステムにおいて、特権昇格の脆弱性が存在する可能性があります。これにより、攻撃者がシステム権限を不正に取得し、情報漏えいやシステム停止、不正取引に繋がるリスクがあります。

推奨アクション

  • Microsoftからの公式パッチ提供情報を継続的に監視し、公開され次第、速やかに適用計画を策定する。
  • Microsoft Defenderの稼働状況と設定を再確認し、可能な範囲でセキュリティ強化策を検討・実施する。
  • 委託先を含め、Microsoft Defenderを利用している全てのシステムについて、本脆弱性の影響範囲を緊急で調査する。

ジュニアハッカーは、C2 がオフラインになった後も Tailscale と OpenSSH を使用してアクセスを維持しました

重要度 中

要約

ハッカーがフランスの自動車企業に侵入し、キーロガーで認証情報を窃取後、C2サーバー停止に備えOpenSSHとTailscaleを導入し永続的なアクセス経路を確保しました。

金融機関への影響

金融機関のシステムや業務への直接的な影響は低いですが、委託先や取引先が同様の手口で侵害された場合、サプライチェーンリスクとして情報漏えいや不正取引に繋がる可能性があります。

推奨アクション

  • 委託先や取引先に対し、OpenSSHやTailscaleなどのリモートアクセスツールの利用状況と管理体制について確認を推奨します。
  • 自組織のシステムにおいて、許可されていないリモートアクセスツールの導入がないか、定期的な棚卸しと監視を強化してください。
  • 従業員に対し、不審なソフトウェアのインストールや認証情報の取り扱いに関するセキュリティ教育を再徹底してください。
