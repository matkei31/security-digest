CISA、Lantronix EDS5000の重大な欠陥が積極的に悪用されていると警告

重要度 高

要約

CISAがLantronix EDS5000シリーズの重大な脆弱性CVE-2025-67038が積極的に悪用されていると警告しました。

金融機関への影響

Lantronix EDS5000シリーズをシステムやネットワーク機器に利用している場合、不正アクセスや情報漏えいのリスクがあります。特に、データセンターや重要インフラ関連のシステムに組み込まれている場合は、業務停止に繋がる可能性があります。委託先での利用状況も確認が必要です。

推奨アクション

  • Lantronix EDS5000シリーズの利用有無をシステム管理者および委託先に緊急で確認する。
  • 該当製品が利用されている場合、CISAの指示に従い、速やかにパッチ適用または緩和策を実施する。
  • パッチ適用が困難な場合は、当該機器のネットワーク隔離やアクセス制限を検討し、監視を強化する。

Amadey と StealC マルウェア ネットワークが中断され、盗まれた 2,700 万の認証情報が回復

重要度 中

要約

欧州刑事警察機構（ユーロポール）が、AmadeyおよびStealCマルウェアのインフラを停止させ、2,700万件の認証情報を回収したと公表しました。

金融機関への影響

顧客の認証情報が窃取されている可能性があり、不正ログインや金融詐欺のリスクが高まります。システムへの直接的な影響は低いものの、顧客資産保護のための監視強化が必要です。

推奨アクション

  • 顧客への注意喚起と、多要素認証の利用推奨を検討する。
  • 不正ログインや不審な取引に関する監視体制を強化し、アラート基準を見直す。
  • 関連するセキュリティベンダーからの追加情報収集と、自社システムへの影響有無を確認する。

攻撃者は Cisco SD-WAN の欠陥を公開の 2 か月前に攻撃

重要度 高

要約

Dark Readingによると、Cisco SD-WANの脆弱性が公表の2ヶ月前から攻撃者に悪用され、管理者権限とルートレベルのアクセスが取得されていたと研究者が指摘しています。

金融機関への影響

Cisco SD-WANを利用している金融機関は、ネットワークインフラの不正アクセス、情報漏えい、システム停止のリスクがあります。特に、委託先が利用している場合も影響が懸念されます。

推奨アクション

  • Cisco SD-WAN製品の利用有無とバージョンを緊急で確認し、脆弱性の影響範囲を特定する。
  • Ciscoからの公式情報を確認し、パッチ適用や緩和策を速やかに実施する。
  • SD-WAN関連のログを調査し、不正アクセスの痕跡がないか確認する。
