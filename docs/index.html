緊急 - セキュリティ上の脅威を理由に、ShareFile のお客様に Storage Zone Controller をシャットダウンするよう進捗状況が伝えられています

重要度 高本日確認カテゴリ：脆弱性・パッチ
悪用確認済みパッチサプライチェーン

何が起きた

Progress Softwareは、ShareFileの顧客に対し、セキュリティ上の脅威に対応するため、Storage Zone Controllersを実行しているWindowsサーバーをシャットダウンするよう指示しました。同社は「外部からの信頼できるセキュリティ脅威」に対応中であり、影響を受けるアカウントへのアクセスを一時的に無効化しています。

なぜ金融機関に関係する

ShareFileのStorage Zone Controllersを利用している金融機関は、業務継続性やデータセキュリティに直接的な影響を受ける可能性があります。指示に従わない場合、情報漏えいやシステム停止のリスクが高まります。

確認すべきこと

  • ShareFileのStorage Zone Controllersを利用している場合、Progress Softwareからの指示に従い、速やかに該当サーバーをシャットダウンする。
  • Progress SoftwareおよびShareFileからの公式情報を継続的に監視し、追加の指示やパッチ提供に備える。
  • シャットダウンによる業務影響を評価し、代替手段や緊急時対応計画を確認する。

Injective Labs GitHub の侵害により、ウォレット キーを盗む npm パッケージがプッシュされる

重要度 中今週確認カテゴリ：インシデント
サプライチェーンインシデント情報漏えい

何が起きた

Injective LabsのGitHubリポジトリが侵害され、攻撃者が悪意のあるnpmパッケージ「@injectivelabs/sdk-ts@1.20.21」を公開しました。このパッケージは、仮想通貨ウォレットの秘密鍵やニーモニックフレーズを窃取する機能を持っていました。

なぜ金融機関に関係する

金融機関が仮想通貨関連サービスを提供している場合、または開発環境で当該SDKを使用している場合、顧客資産の窃取や情報漏えいのリスクに直結する可能性があります。サプライチェーン攻撃の一種として、開発プロセスにおけるセキュリティ対策の重要性を示唆します。

確認すべきこと

  • 仮想通貨関連サービスを提供している場合、利用しているSDKのバージョンを確認し、悪意のあるバージョンが使用されていないか調査する。
  • 開発環境におけるサプライチェーンセキュリティ対策（依存関係のスキャン、レジストリの監視など）の有効性を再評価する。
  • 開発者に対して、npmパッケージの利用におけるセキュリティベストプラクティス（署名検証、信頼できるソースの利用など）を再周知する。

U-Boot の 6 つの新たな欠陥により、悪意のあるイメージがデバイスをクラッシュさせたり、起動時にコードを実行したりする可能性があります

CVEパッチサプライチェーン

何が起きた

ファームウェアセキュリティ企業Binarlyの研究者が、U-Bootに6つの新たな脆弱性を発見しました。これらの脆弱性は、ホームルーターやスマートカメラ、データセンターサーバーの管理チップなど、様々なハードウェアの起動プログラムに影響を与えます。

デバイスにバインドされたセッション認証情報による Cookie の保護

重要度 中今週確認カテゴリ：攻撃・脅威動向
認証フィッシング

何が起きた

Google TAGは、クッキー盗難攻撃からユーザーセッションを保護するための新しい認証技術「Device Bound Session Credentials (DBSC)」について解説しています。DBSCは、セッションクッキーをデバイスに紐付けることで、盗まれたクッキーが他のデバイスで悪用されるのを防ぎます。

なぜ金融機関に関係する
