レーザー攻撃により、パッチが適用できないカードの Tangem ウォレットのパスワードがリセットされる

重要度 中

要約

Ledgerのセキュリティチームが、Tangem製仮想通貨ウォレットカードのチップにレーザーを照射することで、パスワードを任意の値にリセットできる脆弱性を公表しました。

金融機関への影響

Tangemウォレットカードを顧客資産管理や社内業務で利用している場合、物理的な攻撃による資産流出リスクがあります。委託先が利用している場合も同様のリスクが生じます。

推奨アクション

  • Tangemウォレットカードの利用有無をシステム部門および関連業務部門に確認し、利用がある場合は利用状況を把握する。
  • Tangemウォレットカードを利用している場合、物理的なセキュリティ対策を強化し、保管状況やアクセス管理を再確認する。
  • 委託先がTangemウォレットカードを利用しているか確認し、利用している場合はセキュリティ対策状況について情報収集を行う。

研究者が OpenClaw の 3 つの欠陥を使用した WhatsApp からホストへの攻撃チェーンを詳しく説明

重要度 中

要約

金融機関への影響

推奨アクション

  • OpenClaw AIアシスタントの利用有無、および関連するサードパーティ製品での組み込み状況をシステム部門と情報システム子会社に確認する。
  • OpenClaw AIアシスタントを利用している場合、速やかにパッチ適用状況を確認し、未適用であれば緊急で適用を計画・実施する。
  • OpenClaw AIアシスタントを直接利用していない場合でも、委託先やクラウドサービスプロバイダーでの利用状況を確認し、影響範囲を把握する。

新しい MODBEACON RAT は、暗号化された C2 トラフィックに gRPC ストリーミングを使用します

重要度 中

要約

中国関連のサイバー犯罪グループSilver Foxが、gRPCストリーミングを利用するRustベースの新型RAT「MODBEACON」を使用しているとQiAnXinが公表しました。

金融機関への影響

金融機関のシステムが偽インストーラー経由で感染するリスクがあります。特に、従業員のPCや業務システムが標的となる可能性があり、情報漏えいや不正アクセスのリスクが高まります。

推奨アクション

  • セキュリティ製品のログを監視し、MODBEACON RATの活動を示す不審な通信やプロセスがないか確認する。
  • 従業員に対し、SEOポイズニングによる偽インストーラーの危険性について注意喚起し、正規サイトからのダウンロードを徹底させる。
  • EDR等のエンドポイントセキュリティ製品が最新の状態であり、未知の脅威に対する検知能力が適切に設定されているか確認する。

重要度 中

要約

Cisco TalosがWolfSSL、GeoVision、VTK-DICOMの計18件の脆弱性を公表しました。これらの脆弱性は各ベンダーによって既に修正済みです。

金融機関への影響

WolfSSLは組み込みシステムやIoTデバイスで利用される可能性があり、金融機関の利用するシステムや委託先の機器に影響する可能性があります。GeoVisionは監視システム、VTK-DICOMは医療画像処理に関連し、直接的な影響は限定的ですが、関連業務や委託先での利用がないか確認が必要です。

推奨アクション

  • WolfSSLを利用している場合は、ベンダーの修正パッチが適用されているか、または適用計画を確認してください。
  • GeoVisionやVTK-DICOMが金融機関の業務システムや委託先で利用されていないか確認し、利用がある場合は修正状況を確認してください。
