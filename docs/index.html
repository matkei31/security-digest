休眠中の GitHub アカウントは、企業組織のマッピング中に攻撃者が溶け込むのに役立ちます

重要度 中

要約

Datadog Security Labsが、休眠中のGitHubアカウントや侵害されたOAuthトークンを利用し、企業GitHub組織、リポジトリ、ユーザーアカウントを体系的に列挙する複数の攻撃キャンペーンについて警告しました。

金融機関への影響

金融機関がGitHubを開発や情報共有に利用している場合、リポジトリやユーザー情報が攻撃者に列挙されるリスクがあります。委託先がGitHubを利用している場合も同様に情報漏えいの懸念があります。

推奨アクション

  • 自社および主要な委託先におけるGitHubの利用状況と公開範囲を確認し、機密情報が含まれていないか点検する。
  • GitHubアカウントの棚卸しを実施し、長期間利用されていない休眠アカウントや不審なOAuthトークンがないか調査する。
  • GitHubの監査ログを定期的に監視し、不審なAPIアクセスや情報列挙の兆候がないか確認する。
The Hacker News 07/09 23:38

新しい GigaWiper Windows バックドア バンドル ディスク ワイピング、偽のランサムウェア、スパイウェア

重要度 中

要約

Microsoftが「GigaWiper」と呼ぶ破壊的なWindowsバックドアを分析しました。これは、ディスクワイプ、Windowsドライブ上書き、偽のランサムウェア機能を組み合わせたものです。

金融機関への影響

Windows環境を利用するシステムや端末が標的となる可能性があります。特に、顧客情報や取引データを扱うシステムへの侵入は、データ破壊や業務停止、信頼失墜のリスクを高めます。委託先のWindows環境も確認が必要です。

推奨アクション

  • Microsoft製品のセキュリティパッチ適用状況を確認し、最新の状態を維持してください。
  • EDR/MDR等の監視システムでGigaWiperに関連する不審な活動がないかログを調査してください。
  • 従業員に対し、不審なメールやリンクを開かないよう注意喚起とセキュリティ教育を強化してください。
The Hacker News 07/09 22:19

npm 12 はサプライ チェーンのリスクを軽減するためにデフォルトでインストール スクリプトを無効にします

重要度 中

要約

GitHubはnpm v12をリリースし、サプライチェーンリスク軽減のためインストールスクリプトをデフォルトで無効化しました。また、2FAを回避するGATsは非推奨となります。

金融機関への影響

npmを利用した開発環境やCI/CDパイプラインに影響があります。依存関係のインストール時にスクリプト実行が必要な場合、ビルドエラーや機能不停止のリスクがあります。委託先の開発プロセスにも影響する可能性があります。

推奨アクション

  • npm v12へのアップデート計画を確認し、インストールスクリプトの実行有無と影響を評価する。
  • 開発部門や委託先に対し、npm v12の変更点と対応状況について情報収集を行う。
  • GATsの利用状況を確認し、非推奨化に伴う代替認証方式への移行計画を策定する。

Microsoft Security 07/09 15:00

GigaWiper: 複数のマルウェアから組み立てられた破壊的なバックドアの構造

重要度 高

要約

Microsoft Securityが、複数のマルウェアの機能を組み合わせた破壊的なバックドア「GigaWiper」について分析を公表しました。このマルウェアはデータ消去やランサムウェアのような機能を持つとされています。

金融機関への影響

GigaWiperはデータ破壊能力を持つため、金融機関の基幹システム、情報系システム、顧客情報管理システムに甚大な被害をもたらす可能性があります。システム停止、データ消失、業務中断、復旧コスト増大のリスクがあります。また、委託先のシステムが感染した場合、サプライチェーン全体に影響が及ぶ可能性も考慮する必要があります。

推奨アクション

  • 組織内の全システムに対し、GigaWiperの検出ルールが適用されているか、セキュリティ製品の定義ファイルを最新化し確認する。
  • 不審な通信やファイル活動がないか、ログ監視システムやEDR/XDRの検知状況を緊急で確認し、異常があれば即座に隔離・調査を行う。
  • 重要なデータやシステムのバックアップが最新かつ復元可能であることを確認し、緊急時の復旧手順を再確認する。
