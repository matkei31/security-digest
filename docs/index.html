緊急 - セキュリティ上の脅威を理由に、ShareFile のお客様に Storage Zone Controller をシャットダウンするよう進捗状況が伝えられています

重要度 高本日確認カテゴリ：脆弱性・パッチ
悪用確認済みパッチサプライチェーン

何が起きた

Progress Softwareは、ShareFileのStorage Zone Controllerを使用している顧客に対し、セキュリティ脅威に対応するため、Windowsサーバー上のStorage Zone Controllerをシャットダウンするよう指示しました。同社は「外部からの信頼できるセキュリティ脅威」に対応中であり、影響を受けるアカウントへのアクセスを一時的に無効化しています。

なぜ金融機関に関係する

ShareFileのStorage Zone Controllerを利用している金融機関は、業務継続性やデータセキュリティに直接的な影響を受ける可能性があります。指示に従わない場合、情報漏えいやシステム停止のリスクが高まります。

確認すべきこと

  • ShareFileのStorage Zone Controllerの利用状況を確認し、Progress Softwareからの指示に従い、該当するサーバーをシャットダウンする。
  • Progress Softwareからの公式発表やセキュリティアドバイザリを継続的に監視し、追加の指示やパッチ情報に迅速に対応する。
  • シャットダウンによる業務影響を評価し、代替手段や緊急時対応計画を検討・実施する。

何が起きた

Injective LabsのGitHubリポジトリが侵害され、攻撃者は悪意のあるnpmパッケージを公開しました。このパッケージは、仮想通貨ウォレットの秘密鍵やニーモニックフレーズを窃取する機能を持っていました。

なぜ金融機関に関係する

確認すべきこと

  • 開発環境で使用しているnpmパッケージに不審なバージョンがないか確認する。
  • サプライチェーンリスク管理の一環として、利用しているオープンソースライブラリや開発ツールのセキュリティ監視を強化する。
  • 仮想通貨関連サービスを提供している場合、顧客資産の保護策とインシデント対応計画を見直す。

U-Boot の 6 つの新たな欠陥により、悪意のあるイメージがデバイスをクラッシュさせたり、起動時にコードを実行したりする可能性があります

重要度 中今週確認カテゴリ：脆弱性・パッチ
パッチサプライチェーン

何が起きた

ファームウェアセキュリティ企業Binarlyの研究者が、U-Bootに6つの新たな脆弱性を発見しました。これらの脆弱性は、ホームルーターやスマートカメラ、データセンターサーバーの管理チップなど、様々なハードウェアの起動時に悪意のあるイメージを介してデバイスをクラッシュさせたり、コードを実行させたりする可能性があります。

なぜ金融機関に関係する

U-Bootは幅広い組み込みデバイスで利用されており、金融機関が利用するネットワーク機器、IoTデバイス、データセンターのサーバー管理チップなどに影響を与える可能性があります。これらの脆弱性が悪用された場合、システム停止や不正アクセスにつながる恐れがあります。

確認すべきこと

  • 自組織で利用している機器にU-Bootが使用されているかを確認する。
  • U-Bootを使用している機器のベンダーから、本脆弱性に関する情報提供やパッチの有無を確認する。
  • 該当する機器がある場合、ベンダーの指示に従い、必要な対策を検討・実施する。

CrowdStrike

ガードレールのない AI ガバナンスが劇場である理由

重要度 中今週確認カテゴリ：AI・新技術リスク
AIガイドライン規制

何が起きた

CrowdStrikeは、AIガバナンスが実効性を持つためには、具体的なガードレール（安全策）の導入が不可欠であると指摘しています。ガードレールがなければ、AIガバナンスは形だけのものになりかねません。

なぜ金融機関に関係する

金融機関がAI技術を導入・活用する際、適切なガバナンス体制と具体的な安全策を講じなければ、潜在的なリスク（誤情報、プライバシー侵害、セキュリティ脆弱性など）に晒される可能性があります。これにより、規制遵守違反や風評被害、システム障害につながるリスクがあります。

確認すべきこと

  • AI利用における既存のガバナンスフレームワークやポリシーに、具体的なガードレールが組み込まれているかを確認する。
  • AIシステムの導入・運用に際し、リスク評価と緩和策としてのガードレール設計が適切に行われているかを評価する。
  • AI関連の規制動向やベストプラクティスを継続的に監視し、自社のAIガバナンス体制に反映させることを検討する。

デバイスにバインドされたセッション認証情報による Cookie の保護

重要度 中今週確認カテゴリ：攻撃・脅威動向
認証

何が起きた

Google TAGは、Device Bound Session Credentials (DBSC) を用いたCookie保護の技術について解説しており、これによりセッションハイジャック攻撃への耐性が向上すると説明しています。
