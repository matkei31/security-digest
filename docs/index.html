要約

XQUIC のパッチが適用されていない XRING の欠陥により、リモート クライアントが HTTP/3 サーバーをクラッシュさせる

重要度 中

要約

FoxIOの研究者が、AlibabaのQUICおよびHTTP/3ライブラリXQUICに「XRING」と名付けられた未パッチの脆弱性を公表しました。これにより、リモートクライアントが正当なトラフィックでHTTP/3サーバーをクラッシュさせることが可能です。

金融機関への影響

XQUICを直接または間接的に利用しているシステム（特にHTTP/3対応のWebサーバーやAPIゲートウェイ）は、サービス停止のリスクがあります。Alibaba Cloudなどのクラウドサービス利用時も、基盤技術としてXQUICが使われているか確認が必要です。顧客向けサービスや内部システムへの影響を評価する必要があります。

推奨アクション

  • 自組織のシステムおよび利用中のクラウドサービスや委託先システムにおいて、XQUICライブラリまたはHTTP/3プロトコルが利用されているかを確認する。
  • XQUICの利用が確認された場合、当該システムのサービス継続性への影響を評価し、Alibabaからのパッチ提供状況や回避策について情報収集を継続する。
  • XQUICの利用が不明な場合でも、HTTP/3対応のWebサーバーやAPIゲートウェイの構成を再確認し、関連する脆弱性情報に注意を払う。

  • GeoVision、VTK-DICOMを利用しているシステムや委託先がないか確認し、関連する場合はベンダーの修正適用状況を確認する。

Microsoft Security 07/09 15:00

GigaWiper: 複数のマルウェアから組み立てられた破壊的なバックドアの構造

重要度 高

要約

Microsoft Securityが、複数のマルウェアの機能を組み合わせた破壊的なバックドア「GigaWiper」について分析を公表しました。このマルウェアはデータ消去やランサムウェアのような機能を持つと報告されています。

金融機関への影響

金融機関の基幹システム、情報系システム、顧客情報管理システム、またはそれらを運用する委託先のシステムがGigaWiperに感染した場合、データ破壊や業務停止、情報漏えい、顧客へのサービス提供停止のリスクがあります。

推奨アクション

  • 自組織および主要な委託先において、GigaWiperの検出・防御策が導入されているか、セキュリティ製品のベンダー情報を確認する。
  • セキュリティ監視体制を強化し、GigaWiperに関連する不審な活動や通信がないか、ログの監視と分析を徹底する。
  • 万一の感染に備え、重要なシステムやデータのバックアップが適切に取得され、復旧手順が確立されているかを確認する。
