緊急 - セキュリティ上の脅威を理由に、ShareFile のお客様に Storage Zone Controller をシャットダウンするよう進捗状況が伝えられています

重要度 高

要約

Progress Softwareは、ShareFileのStorage Zone Controllerを使用している顧客に対し、セキュリティ上の脅威に対応するため、Windowsサーバーのシャットダウンを指示しました。同社は、影響を受けるアカウントへのアクセスを一時的に無効化しています。

金融機関への影響

ShareFileのStorage Zone Controllerを利用している金融機関は、業務停止やデータアクセスの中断といった影響を受ける可能性があります。迅速な対応が求められます。

推奨アクション

  • ShareFileのStorage Zone Controllerを利用している場合、Progress Softwareからの指示に従い、速やかに該当サーバーをシャットダウンする。
  • 影響範囲と業務継続への影響を評価し、代替手段の検討または復旧計画を確認する。
  • Progress Softwareからの追加情報やパッチ提供状況を継続的に監視し、必要な対策を講じる。
The Hacker News 07/10 21:59

Injective Labs GitHub の侵害により、ウォレット キーを盗む npm パッケージがプッシュされる

重要度 中

要約

Injective LabsのGitHubリポジトリが侵害され、攻撃者は悪意のあるnpmパッケージを公開しました。このパッケージは、仮想通貨ウォレットの秘密鍵やニーモニックフレーズを窃取する機能を持っていました。

金融機関への影響

金融機関が仮想通貨関連サービスを提供している場合や、開発環境でInjective LabsのSDKを使用している場合、サプライチェーンリスクとして影響を受ける可能性があります。顧客資産の損失や信頼失墜につながる可能性があります。

推奨アクション

  • 自組織の開発環境や利用しているサードパーティ製ソフトウェアにおいて、Injective LabsのSDKや関連npmパッケージの利用状況を確認する。
  • 利用している場合は、影響を受けたバージョン（@injectivelabs/sdk-ts@1.20.21）が導入されていないか確認し、速やかに安全なバージョンに更新する。
  • サプライチェーンリスク管理の一環として、開発ツールやライブラリのセキュリティ検証プロセスを再確認する。
The Hacker News 07/10 21:27

U-Boot の 6 つの新たな欠陥により、悪意のあるイメージがデバイスをクラッシュさせたり、起動時にコードを実行したりする可能性があります

重要度 中

要約

ファームウェアセキュリティ企業Binarlyの研究者が、U-Bootに6つの新たな脆弱性を発見しました。これらの脆弱性は、ホームルーター、スマートカメラ、データセンターサーバーの管理チップなど、様々なハードウェアの起動プログラムに影響を与えます。

金融機関への影響

U-Bootは幅広い組み込みシステムで利用されており、金融機関が利用するネットワーク機器、IoTデバイス、データセンターのサーバー管理チップなどに影響を与える可能性があります。悪用された場合、デバイスのクラッシュや不正なコード実行により、システム停止や情報漏えいにつながるリスクがあります。

推奨アクション

  • 自組織で利用している機器やシステムにU-Bootが組み込まれているかを確認する。
  • U-Bootを利用している場合、ベンダーからのセキュリティアップデートやパッチ提供状況を監視し、適用計画を検討する。
  • サプライチェーンを通じて導入される機器のファームウェアセキュリティについて、調達基準や委託先管理の観点から再確認する。

CISA KEV 07/10 00:00

CVE-2026-56291 — Balbooa フォーム、危険なタイプの脆弱性を持つファイルの無制限アップロード

重要度 高

要約

Balbooa Formsに危険な種類のファイルを無制限にアップロードできる脆弱性(CVE-2026-56291)が発見され、認証されていない攻撃者が実行ファイルをアップロードし、リモートコード実行(RCE)が可能になる可能性があります。

金融機関への影響

推奨アクション

  • 自組織でBalbooa Formsの利用状況を確認する。
  • 該当製品を利用している場合、ベンダーからのパッチや緩和策の情報を確認し、速やかに適用を検討する。
  • 当該製品に対する不審なファイルアップロードやアクセスがないか、ログ監視を強化する。
CISA KEV 07/10 00:00

CVE-2026-48939 — iCagenda による危険なタイプの脆弱性のあるファイルの無制限アップロード

重要度 高

要約

iCagendaに危険な種類のファイルを無制限にアップロードできる脆弱性(CVE-2026-48939)が存在し、これにより任意のファイルをアップロードしてPHPコードを実行される可能性があります。

金融機関への影響

iCagendaを利用している金融機関では、システムへの不正アクセスや情報漏えい、業務停止などのリスクが生じる可能性があります。

推奨アクション

  • iCagendaの利用状況を確認し、該当製品を使用している場合は速やかにベンダーからのパッチ適用や緩和策の実施を検討する。
  • システムログの監視を強化し、不審なファイルアップロードやPHPコード実行の兆候がないか確認する。
  • ウェブアプリケーションファイアウォール(WAF)等のセキュリティ対策が適切に設定されているか確認し、必要に応じて強化する。
CrowdStrike

ガードレールのない AI ガバナンスが劇場である理由

重要度 中

要約

CrowdStrikeは、AIガバナンスが実効性を持つためには、具体的なガードレール（安全策）が不可欠であると指摘しています。ガードレールがなければ、AIガバナンスは形だけのものになりかねません。

金融機関への影響

金融機関がAI技術を導入・活用する際、単にAIガバナンス体制を構築するだけでなく、具体的なリスク軽減策としてのガードレールを実装しなければ、潜在的なリスクを適切に管理できない可能性があります。

推奨アクション

  • AI利用における具体的なガードレール（安全策）の策定状況を確認する。
  • AIガバナンスフレームワークが、技術的・運用的なガードレールと連携しているか評価する。
  • AI導入プロジェクトにおいて、リスク評価とガードレール実装が計画に含まれているか確認する。
