イラン関連のハッカーが新しいCavern C2フレームワークを使用してイスラエルの組織を標的に

重要度 中

要約

イラン政府系ハッカー集団が、イスラエル組織を標的に、未確認のC2フレームワーク「Cavern」を使用していることをCheck Point Researchが公表しました。

金融機関への影響

直接的な金融機関への影響は低いものの、ITプロバイダーが標的とされているため、委託先のセキュリティ状況を確認する必要があります。サプライチェーンリスクとして間接的な影響が生じる可能性があります。

推奨アクション

  • 主要なIT委託先に対し、本攻撃フレームワークへの対策状況を確認する。
  • 自組織のシステムログを監視し、不審なC2通信がないか定期的に確認する。
  • 脅威インテリジェンスを継続的に収集し、関連する攻撃手法やIoCに注意を払う。

16 年前の Linux KVM の欠陥により、ゲスト VM が Intel および AMD x86 システム上のホストに逃げてしまう

重要度 高

要約

Linux KVMハイパーバイザーに16年前から存在する脆弱性（CVE-2026-53359）が公表され、ゲストVMからホストカーネルのメモリを破壊し、ホストからの脱出が可能となる恐れがあります。

金融機関への影響

KVMを利用する仮想化基盤を持つ金融機関は、情報漏えいやシステム停止のリスクがあります。特に、顧客情報や機密データを扱うシステム、または外部に公開されているシステムでKVMを使用している場合、不正アクセスやサービス停止に直結する可能性があります。委託先がKVMを使用している場合も同様のリスクがあります。

推奨アクション

  • 自組織および委託先におけるLinux KVMの利用状況を確認し、脆弱性の影響を受けるシステムを特定する。
  • KVMを利用しているシステムについて、ベンダーからのパッチ提供状況を監視し、速やかに適用計画を策定・実行する。
  • KVM環境におけるセキュリティ監視を強化し、異常な挙動やアクセスがないかログを詳細に確認する。

脅威アクターが Gitea Docker の欠陥 CVE-2026-20896 を公開から 13 日後に調査

重要度 高

要約

Sysdigによると、Gitea Dockerイメージの深刻な脆弱性CVE-2026-20896が悪用されようとしていることが確認されました。認証なしで特権昇格が可能になります。

金融機関への影響

Gitea Dockerを利用しているシステムは、認証なしで特権昇格されるリスクがあります。情報漏えいやシステム停止、不正取引につながる可能性があり、委託先での利用状況も確認が必要です。

推奨アクション

  • Gitea Dockerイメージの利用有無を確認し、利用している場合は速やかにパッチ適用または緩和策を講じる。
  • Gitea Dockerを利用している委託先に対し、本脆弱性の対応状況を確認し、必要に応じて改善を要請する。
  • Gitea Docker関連システムのアクセスログを監視し、不審なアクセスや特権昇格の兆候がないか確認する。
