16 年前の Linux KVM の欠陥により、ゲスト VM が Intel および AMD x86 システム上のホストに逃げてしまう

重要度 高

要約

Linux KVMハイパーバイザーに16年前から存在する脆弱性（CVE-2026-53359）が公表され、ゲストVMからホストカーネルのシャドウページ状態を破壊できることが判明しました。

金融機関への影響

Linux KVMを利用する仮想化基盤を持つ金融機関は、ゲストVMからのホストOSへの不正アクセスや情報漏えい、システム停止のリスクがあります。特に、本番環境や機密情報を扱うシステムでの利用状況を確認する必要があります。

推奨アクション

  • Linux KVMの利用有無とバージョンを確認し、脆弱性の影響を受けるシステムを特定する。
  • ベンダーからのパッチ提供状況を監視し、速やかに適用計画を策定・実行する。
  • KVM環境におけるセキュリティ監視を強化し、異常な挙動がないかログを詳細に確認する。

脅威アクターが Gitea Docker の欠陥 CVE-2026-20896 を公開から 13 日後に調査

重要度 高

要約

Sysdigによると、Gitea Dockerイメージの深刻な脆弱性CVE-2026-20896が悪用されようとしていることが確認されました。この脆弱性は、認証なしで特権昇格を可能にします。

金融機関への影響

Gitea DockerをCI/CDパイプラインや開発環境で利用している場合、システムへの不正アクセス、情報漏えい、コード改ざんのリスクがあります。委託先での利用状況も確認が必要です。

推奨アクション

  • Gitea Dockerイメージの利用有無を確認し、利用している場合は速やかに最新版へアップデートしてください。
  • Gitea Dockerイメージの利用状況について、開発部門および外部委託先へ緊急で確認を実施してください。
  • Gitea Dockerがインターネットに公開されている場合、アクセスログを監視し不審な通信がないか確認してください。

ClickOnce テクノロジーの新たな悪用、パート 2: 脅威アクターが一度クリックすると永久に留まるのを阻止する

重要度 中

要約

CrowdStrikeが、MicrosoftのClickOnce技術を悪用した新たな攻撃手法について報告しました。これにより、攻撃者は永続的なアクセスを確立する可能性があります。

金融機関への影響

ClickOnceを利用するシステムやアプリケーションがある場合、マルウェア感染や情報窃取のリスクがあります。特に、業務アプリケーションや顧客向けサービスでの利用状況を確認し、委託先が利用している可能性も考慮する必要があります。

推奨アクション

  • ClickOnceを利用している社内システムやアプリケーション、および委託先の利用状況を調査し、リスクを評価してください。
  • ClickOnceアプリケーションの配布元が信頼できるか確認し、不審なアプリケーションの実行を制限する対策を検討してください。
  • エンドポイントセキュリティ製品のログを監視し、ClickOnce関連の不審な挙動がないか定期的に確認してください。

現実の AI の脅威: Web 上でのプロンプト インジェクションの現状

重要度 中

要約

Googleの脅威分析グループ(TAG)が、AIモデルへのプロンプトインジェクション攻撃がウェブ上で増加している現状を公表しました。

金融機関への影響

金融機関が利用するAIチャットボットや生成AIサービスにおいて、機密情報の漏洩や誤情報の生成、不正な操作を誘発するリスクがあります。特に顧客対応システムや社内業務支援システムへの影響が懸念されます。

推奨アクション

  • AIを利用するシステムやサービスにおいて、プロンプトインジェクション対策が講じられているかベンダーに確認する。
  • AIモデルへの入力データや出力結果の監視を強化し、不審な挙動がないか定期的にチェックする。
  • AI利用ガイドラインを策定し、機密情報を入力しない、出力結果を鵜呑みにしないなどの注意喚起を徹底する。
