中国関連の JDY ボットネット、サイバー偵察用に 1,500 台以上のデバイスに拡大

重要度 中

要約

サイバーセキュリティ研究者が、中国関連の国家支援型脅威アクターと関連するJDYボットネットが1,500以上のSOHOおよびIoTデバイスに拡大し、サイバー偵察活動を行っていると警告しました。

金融機関への影響

金融機関のSOHO/IoTデバイスが直接の標的となる可能性は低いですが、委託先やサプライチェーン上の企業がJDYボットネットに感染し、そこを踏み台とした偵察活動や攻撃に繋がるリスクがあります。

推奨アクション

  • 委託先や関連会社に対し、SOHO/IoTデバイスのセキュリティ対策状況（パッチ適用、パスワード強化等）を確認するよう促す。
  • 自組織のネットワーク境界における不審なスキャン活動や通信がないか、ログ監視を強化し、異常を検知した場合は速やかに調査する。
  • SOHO/IoTデバイスの利用状況を再確認し、不要なデバイスの接続停止や、必要な場合はセグメンテーションによる隔離を検討する。

CISA、AI脅威時代に向けて連邦パッチ適用要件を書き換える

重要度 中

要約

CISAが連邦政府機関向けにパッチ適用要件を改訂し、最も危険な脆弱性には3日以内、それ以外は猶予期間を設ける新たな指令を発表しました。

金融機関への影響

金融機関のシステムや業務への直接的な影響は低いですが、委託先のセキュリティ要件や契約内容に影響を与える可能性があります。特に、連邦政府機関と連携するシステムやサービスを提供する委託先は、この新たな基準への対応が求められる可能性があります。

推奨アクション

  • 委託先管理部門は、連邦政府機関と取引のある委託先に対し、CISAの新たなパッチ適用要件への対応状況を確認する。
  • 自社の脆弱性管理プロセスとパッチ適用ポリシーが、最新の脅威環境に対応しているか定期的に見直す。
  • 情報システム部門は、重要度が高い脆弱性に対する緊急パッチ適用体制が確立されているか確認する。

Ivanti、Fortinet、SAP が複数の重大な脆弱性に対するパッチをリリース

重要度 中

要約

Fortinet、Ivanti、SAPが複数の重大なセキュリティ脆弱性に対するパッチを公開しました。Fortinetの脆弱性CVE-2026-25089はFortiSandboxのコマンドインジェクションに関するものです。

金融機関への影響

FortiSandboxを利用している場合、システムへの不正アクセスや情報漏えいのリスクがあります。委託先が利用している場合も同様のリスクがあるため、確認が必要です。

推奨アクション

  • FortiSandbox製品の利用有無を確認し、利用している場合は速やかにパッチ適用を計画してください。
  • FortiSandboxを利用している委託先がないか確認し、パッチ適用状況を問い合わせてください。
  • SAPおよびIvanti製品の利用有無も確認し、関連する脆弱性情報とパッチ適用計画を確認してください。
