Google Vertex AI SDK の欠陥により、攻撃者がバケット スクワッティングを介してモデルのアップロードをハイジャックできる

重要度 中

要約

Palo Alto Networks Unit 42がGoogle Cloud Vertex AI SDK for Pythonの脆弱性を発見し、攻撃者が被害者のMLモデルアップロードを乗っ取り、Googleのインフラ内でコードを実行できることを公表しました。

金融機関への影響

Google Cloud Vertex AIを利用している金融機関は、MLモデルのアップロードプロセスにおいて、第三者によるコード実行リスクに晒される可能性があります。システム、データ、およびサービス提供への影響を確認する必要があります。

推奨アクション

  • Google Cloud Vertex AI SDK for Pythonの利用状況を確認し、関連するシステムやサービスを特定する。
  • Googleからの公式パッチや推奨される対策が公開されていないか、最新情報を継続的に監視する。
  • Vertex AIを利用したMLモデルのアップロードプロセスにおけるセキュリティ設定とアクセス制御を再確認する。
The Hacker News 06/16 23:11

ClickFix キャンペーン、新しいローダーと偽のアップデートルアーでマルウェア配信を拡大

重要度 高

要約

サイバーセキュリティ研究者が、ClickFixキャンペーンがBabaDeda Loader、Lorem Ipsum Loader、Potemkinという3つの新しいマルウェアローダーを配布していると報告しました。特にBabaDeda Loaderは金融機関を標的としています。

金融機関への影響

BabaDeda Loaderは金融機関を標的としているため、顧客情報漏えい、システム停止、不正取引のリスクがあります。特にインターネットに接続されたシステムや、従業員の利用する端末が影響を受ける可能性があります。委託先のセキュリティ対策も確認が必要です。

推奨アクション

  • BabaDeda Loaderに関連するIOC（Indicator of Compromise）情報を確認し、自社システム内での感染有無を緊急で調査してください。
  • 従業員に対し、不審なメールや偽のアップデート通知に対する注意喚起とセキュリティ教育を強化してください。
  • セキュリティ監視体制を強化し、不審な通信や挙動を早期に検知できるようログ分析を徹底してください。
The Hacker News 06/16 18:40

新しい Rokarolla Android マルウェアが PIN、SMS コード、暗号ウォレット資金を盗む

重要度 高

要約

Zimperiumの研究者が、Androidバンキングトロジャン「Rokarolla」を発見。217の銀行・仮想通貨アプリを標的とし、PIN、SMSコード、仮想通貨ウォレットの資金を窃取する。

金融機関への影響

顧客が利用するモバイルバンキングアプリや仮想通貨アプリが標的となるため、顧客資産の不正送金や情報漏えいのリスクがある。顧客からの問い合わせ増加や信頼失墜にも繋がり得る。

推奨アクション

  • 顧客に対し、不審なアプリのインストールやリンクのクリックを避けるよう注意喚起を行う。
  • モバイルバンキングアプリのセキュリティを再確認し、多要素認証の利用を推奨する。
  • 不正送金や情報漏えいに関する監視体制を強化し、早期検知・対応に努める。
