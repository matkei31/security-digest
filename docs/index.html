Google、200万台のホームデバイスにわたるNetNut住宅用プロキシネットワークを妨害

重要度 中

要約

GoogleはFBIなどと連携し、家庭用デバイスを悪用して他者の通信を中継する大規模な住宅プロキシネットワーク「NetNut」を大幅に縮小させたと公表しました。

金融機関への影響

金融機関のシステムや業務への直接的な影響は低いものの、NetNutのようなプロキシサービスが悪用された場合、不正アクセスや詐欺取引の隠蔽に利用される可能性があります。委託先が意図せず利用している可能性も考慮し、監視を強化する必要があります。

推奨アクション

  • 自社システムへの不正アクセス試行元IPアドレスに、住宅プロキシ経由のものが含まれていないかログを確認する。
  • 委託先が業務で住宅プロキシサービスを利用していないか、契約内容や利用実態を確認する。
  • 不正検知システムにおいて、住宅プロキシ経由のアクセスに対する検知ルールや閾値を再評価し、必要に応じて強化する。

ランサムウェア グループが Citrix Bleed 2、BYOVD、サプライ チェーンの認証情報に注目

重要度 高

要約

AnubisランサムウェアグループがCitrix Bleed 2（CVE-2025-5777）の脆弱性を悪用し、初期アクセスを取得していることが確認されました。

金融機関への影響

Citrix製品を利用しているシステム（特にリモートアクセス、VDI環境）は、ランサムウェアによるシステム停止、情報漏えい、不正取引のリスクに直面します。委託先での利用状況も確認が必要です。

推奨アクション

  • 自社および委託先におけるCitrix Bleed 2（CVE-2025-5777）の影響を受ける製品の利用有無を確認する。
  • 脆弱性が確認された場合、速やかにセキュリティパッチの適用または緩和策を実施する。
  • Citrix製品のログ監視を強化し、不審なアクセスや活動がないか緊急で確認する。

中小企業への圧力が高まる中、オーストラリア人はサイバー犯罪リスクの軽減に直面

重要度 低

要約

Dark Readingが、オーストラリアでは機関の保護強化と規制厳格化により、サイバー犯罪のリスクが中小企業に転嫁されていると報じました。

金融機関への影響

本ニュースはオーストラリアの状況に関するものであり、日本の金融機関への直接的なシステム、業務、委託先への影響は限定的です。ただし、海外拠点や関連会社がオーストラリアに存在する場合、その拠点の中小企業との取引やサプライチェーンにおけるサイバーリスクが増加する可能性があります。

推奨アクション

  • オーストラリアに拠点を持つ、またはオーストラリアの中小企業と取引のある部門に対し、本ニュースの共有と関連リスクの有無を確認する。
  • サプライチェーンリスク管理プロセスにおいて、海外の中小企業委託先に対するサイバーセキュリティ評価基準が適切かを確認する。
  • 自社のサイバーセキュリティ対策が、規制強化や脅威の変化に対応できているか、継続的に評価・改善する。
