Today's Brief

本日の概況

本日は、開発サプライチェーンにおける情報窃取マルウェアの拡散という緊急性の高いインシデントが報告されました。これは金融機関の開発環境に直接的な影響を及ぼす可能性があり、早急な確認が求められます。また、Zimbraの重大な脆弱性やAIモデルに対するプロンプトインジェクション攻撃といった、中長期的なリスクとなり得る脅威に関する情報も複数確認されました。全体として、サプライチェーンリスクとAI関連の新たな脅威への対応が本日の主要な論点となります。

本日の注目論点

  • 開発環境におけるnpmパッケージのサプライチェーンセキュリティ対策と監視体制は十分か、また、広く利用される開発用パッケージの侵害リスクに対し、どのような予防的措置や緊急対応計画が有効か。
  • AI技術の導入が加速する中で、プロンプトインジェクションのような新たな攻撃手法に対するセキュリティ対策を、どのようにAIガバナンスの枠組みに組み込み、リスクを管理していくべきか。
  • セッションハイジャック攻撃からクッキーを保護するDevice Bound Session Credentials (DBSC)のような新しい認証技術について、金融機関の認証セキュリティ強化策として導入の可能性や有効性をどのように評価すべきか。

本日の確認事項

  • jscrambler npmパッケージのバージョン8.14.0が開発環境やCI/CDパイプラインで利用されていないか確認し、利用されている場合は直ちに利用を停止し、感染の有無を確認してください。
  • Zimbra Classic Web Clientを利用している場合、ベンダーが提供するアップデートの適用状況を確認し、必要に応じて適用を検討してください。
  • AIモデルやLLMを組み込んだアプリケーションを利用している場合、プロンプトインジェクションに対するセキュリティ対策の現状を確認し、導入を検討している場合は設計段階から対策を考慮してください。
  • 開発環境におけるnpmパッケージのサプライチェーンセキュリティ対策と監視体制について、現状の有効性を評価し、必要に応じて見直しを検討してください。

1.Compromised jscrambler 8.14.0 npm Release Drops Rust Infostealer During Install侵害された jscrambler 8.14.0 npm リリースにより、インストール中に Rust Infostealer がドロップされる

確認優先度 高確認目安 本日確認カテゴリ：インシデント
関連タグ：サプライチェーンインシデント情報漏えい

何が起きた

jscramblerのnpmパッケージバージョン8.14.0が侵害され、インストール時に情報窃取マルウェアが実行される事態が発生しました。この悪意あるバージョンは2026年7月11日に公開され、Windows、macOS、Linux向けのネイティブバイナリをドロップ・実行するpreinstallフックを含んでいます。

なぜ金融機関に関係する

金融機関が開発プロセスでnpmパッケージを利用している場合、サプライチェーンリスクとして直接的な影響を受ける可能性があります。特に、jscramblerパッケージを直接的または間接的に利用している場合は、情報窃取の被害に繋がる恐れがあります。

確認すべきこと

  • jscrambler npmパッケージのバージョン8.14.0が開発環境やCI/CDパイプラインで利用されていないか確認してください。
  • 当該バージョンが利用されている場合、直ちに利用を停止し、システムへの情報窃取マルウェア感染の有無を確認してください。
  • 開発環境におけるnpmパッケージのサプライチェーンセキュリティ対策と監視体制を見直してください。
